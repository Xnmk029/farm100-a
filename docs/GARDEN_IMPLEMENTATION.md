# 完整农场目标实施记录

更新：2026-09-08。总目标仍为 `PRODUCT_TARGET_V1.md` 所定义的同等级观赏性与系统复杂度。本文件记录实施进展，不缩减总目标，不将阶段成果当作总体验验收。

## 当前已实现

- 新增自由农场工作台，与旧排序测评入口并存。
- 原创 Blender 模型与统一正交渲染资产：8 类作物 × 4 阶段外观、8 向无人机、8 个地块外观和 6 类环境物件，共 54 张透明 PNG。只有小麦和胡萝卜已接入生产规则，其余作物是后续内容的资产基础。
- 新农场采用等距俯视画面，包含土壤干湿、农路、仓棚、水箱、围栏、树木和石块。支持滚轮缩放、拖动平移、点击田块、无人机跟随和观赏模式。
- 作物成长交叉淡入、轻微风动、无人机悬停与旋翼、按模拟时间插值的移动，以及播种、翻土、浇水、收获粒子。视觉动画与计分世界分离。
- 程序通过真实 QuickJS/WASM utility process 执行。API 支持翻土、播种、检查、浇水、补水、收获、移动和等待。
- 小麦提供粮食，胡萝卜种植消耗粮食，补水消耗粮食；自然成长不要求外部时间或联网。水会提升成长速度。脚本不能直接获得宿主文件、网络或系统能力。
- 农场完整事件与阶段快照，可回放、单步、倍速、跳转。从当前显示状态重新执行可形成新的运行分支。
- 农场存档保存当前田地、库存、位置、模拟时间和代码；完整运行包使用 `.farmgarden`。导入逐事件验证，不执行文件内代码。结束记录自动存入 userData/farm100/gardens。
- 本地合成环境风声和动作音效，提供环境/动作独立音量与静音；默认关闭，由用户启用。尚未进行听感验收。

## 新规则的冻结边界

`garden-v0.2.0` 是自由农场的独立规则版本，旧 `sort-field-v1.0` 成本表和回放格式保持原语义。

| 动作 | 模拟持续 tick | 操作成本 |
| --- | ---: | ---: |
| get_size / get_position / inspect | 1 | 1 |
| move | 4 | 1 |
| till | 8 | 1 |
| plant / harvest | 6 | 1 |
| water | 4 | 1 |
| refill | 12 | 1 |
| wait(n)，1 ≤ n ≤ 100 | n | n |

动作先做参数和预算预检，既有作物在持续时间内生长，动作效果在末端提交。刚播种的作物从零成长开始。失败的合法动作仍消耗时间与成本；非法参数和预算不足不改变世界。每次执行的预算是相对于其起始状态的增量上限，累计存档成本继续保留。

小麦湿润时 120 tick 成熟、每次收获 3 粮食；胡萝卜湿润时 160 tick 成熟、播种消耗 1 粮食、收获 2 根菜。干燥时每隔一个 tick 成长，交替相位由格号和种子决定。浇水消耗 1 储水并增加 240 湿润 tick；1 粮食补充 24 储水。

这是 G1 的两作物生产循环；根菜的后续用途、长期解锁与关联生产链属于尚待实施的 G2，不能称当前已具有完整经营深度。

- 相同运行重复事件一致；100 个随机回放点与顺序恢复一致；存档中间状态恢复后续作一致；篡改库存事件被拒绝。
- 真实 Electron utility process 重复执行并验证了相同结果。见 `artifacts/garden/garden-utility.json` 与 `garden-run.farmgarden`。
- 两种窗口尺寸的真实 Electron 画面已检查。首轮发现 1280×720 捕获早于资产就绪；已改为等待资源就绪确认，再捕获画面。资源加载改用普通图片路径，消除了 Pixi worker 对 data URL 的 CSP 报错，未放宽 CSP。
- 动态回放输出已完成短片验证：按每帧模拟 tick 和渲染确认生成 1080p/30fps 离线视频。最新 5 秒片段为 `artifacts/garden/motion-v3/garden-motion-5s.mp4`，150 帧，首帧完整。导出耗时不能当作实时帧率；影片当前无音轨。早期 v1 的墙钟录制速度偏差、v2 的首帧空白已记录并修复，不作为正式演示。
- `0.2.0-alpha.1` 开发预览版已生成于 `release/garden-preview/win-unpacked/`。实际分发版的农场 utility process 和两种窗口尺寸渲染检查均退出 0，记录位于 `artifacts/garden/packaged/`。尚未进行干净 Windows 安装验收。

## 资产制作与复现

源脚本：`scripts/assets/build_farm.py`。

可编辑模型库：`assets/source/farm-library-v1.blend`。所有模型分别存放于命名 collection，当前隐藏渲染以便选择编辑；脚本可重建全部素材。

运行资产与清单：`apps/desktop/public/assets/farm-v1/`。Vite 将这些文件复制到发布内容，客户端不依赖 Blender。

本机复现命令：

```powershell
& 'G:\blender-4.0.1\blender-4.0.1\blender.exe' --background --factory-startup --python-exit-code 1 --python scripts/assets/build_farm.py -- F:\benchmark\FARM100
pnpm test
pnpm build
node node_modules/electron/cli.js . --qa-garden-utility
node node_modules/electron/cli.js . --qa-render --qa-garden
```

使用 Blender 4.0.1 / EEVEE，320×320 透明 PNG，共享正交相机、世界单位和材质。资产均由本项目脚本生成，未下载或复用原版游戏素材；许可随本项目。音效由本项目 Web Audio 代码合成，不使用外部音频样本。
