# 完整农场目标实施记录

更新：2026-09-08。开发预览版本：0.3.0-alpha.1。总目标仍为 PRODUCT_TARGET_V1.md 的 G0–G5；本记录不将阶段成果当作原版同等级验收。

## 已实施的可玩内容

- 自由农场与旧排序测评并存，使用 Electron / React / PixiJS / Monaco / QuickJS utility process。
- 8 类作物具有不同规则：免费麦种与轮作、根菜连作减产、树木间距、向日葵最高性状优先、成熟南瓜 2×2 融合、仙人掌有序连通收获、树豆共生、矿晶裂隙维修。
- 15 种资源、6 种加工配方、农艺/制造/物流 3 个研究分支，共 20 个能力节点。世界从 4×4 开放区域扩建至 6×6、8×8。
- 三条交叉依赖的主链：粮食/根菜→堆肥→土壤与特殊栽培；树木→木材→木板→加工/工具/扩建；向日葵→油籽→植物油→补给/零件；纤维→绳索、豆荚→补给、矿晶→零件把这些链关联起来。
- 程序、研究、加工、任务、手册五页。按钮操作也经真实脚本引擎消耗资源和时间，显示结果终态并保留编辑器代码。
- 12 个基于真实行为计数的引导目标。新档默认是一行小麦的短程序；完整成长参考程序另存 examples/garden-progress.js。引导目标尚不等同于完整的分课教学体验。
- clear() 放弃脚下作物，不消耗库存；满田损坏且无维修材料时仍可清理并种免费小麦恢复生产。
- 保存当前田地、资源、研究、任务计数、位置、模拟时间与代码；导入运行包逐事件复验，不执行其中代码。旧排序与旧 garden-v0.2.0 规则保留。

## 规则与兼容边界

新版为 garden-v0.3.0；config.rule 缺省代表冻结的 garden-v0.2.0，不能自动升级旧记录。旧实现保存在 packages/garden/legacy-v02.ts。存档版本必须与 config.rule 一致。

生长由整数模拟 tick 推进，既有作物在动作持续时间内生长，效果在动作末端提交。播放倍率、暂停与跳转不改变产出。非法参数和预算不足在预检时终止，不修改状态；合法但条件不满足的调用消耗时间并返回 false。每次执行预算相对于起始累计成本计量。

基础 API 保留；新增 get_inventory、get_progress、research、craft、fertilize、water_area、till_area、inspect_neighbors、swap、repair、expand、harvest_area、clear。配方、成本、依赖和作物参数以 packages/garden/content.ts 为准；它们由引擎执行约束，界面只是展示。
