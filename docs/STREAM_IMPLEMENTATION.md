# G5 流式运行与分页回放

更新于 2026-09-10，桌面版本 0.5.2-alpha.1，模拟规则仍为 garden-v0.5.0。整体产品目标尚未完成。

## 当前行为

当前规则的自由农场使用流式运行。QuickJS 运行器只保留尚未确认的事件，每批至多 64 条；宿主通过实际规则引擎逐条校验，持久化后才确认。运行器收到确认后释放该批次。取消不会代替落盘确认，写入错误不会重试同一批次。

完成结果使用独立的 `farm100-garden-receipt` 格式，包含初态、终态、结果、日志和事件总数，不能伪装成事件为空的完整运行。宿主不累积事件数组。脚本错误、预算不足、忙循环、主动取消和进程退出均保留明确结果；每台 VM 的内存与指令保护继续生效。

完整内存运行的原有保护上限继续用于挑战、旧规则及既有测评接口。自由农场流式执行的宿主时间上限为两小时，单次操作预算仍最多 200,000；记录最多 400,016 个事件、16,384 个片段、1 GiB 片段数据，每片段最多 16 MiB。达到磁盘或记录配额后停止执行并保留已提交前缀。这些上限不是无限运行承诺。

## 校验、恢复与跳转

增量校验器只保留当前世界和至多一个同刻完成组。调度器可能提前生成多台机的同刻完成事件，因此另存“已经读到的世界”，避免将片段中途的前缀恢复成未来状态。片段校验是整体事务，任一事件不符合规则便撤回整片段。

打开分页记录时顺序检查头、哈希链、片段前态、动作与结果，不累积完整事件及快照。即便重新计算哈希，伪造的动作结果仍会被规则引擎拒绝。索引每 16 个片段和结束时更新，摘要每批更新；不可变片段始终是恢复依据。旧的完整读取接口对超过 50,000 事件的记录提示改用分页，不能悄悄截断并改写历史。

分页索引支持模拟时间与绝对事件编号定位。桌面保存邻近窗口；窗口外的运动完成事件单独读取，避免多机动作因分页失去轨迹。读取下一页时停止推进播放时钟，已经显示的世界保持稳定，加载完成后继续。打开描述符缓存最多四份，淘汰后再次使用会重新验证。读取时发现片段改变会报错。

`.farmjournal` 是逐行写入的完整运行档案，含记录头、各片段和结束回执。导入逐片段校验，在临时目录完成后发布为新编号，不覆盖已有运行；不完整或伪造档案不会出现在历史列表。保存世界仍使用原来的 `.garden.json`，不恢复 JavaScript 调用栈。挑战 `.farmgarden` 和旧排序 `.farmrun` 流程保留。

## 验证与证据

自动化测试覆盖 1/2/4/8 机与单机的流式/完整事件一致性、延迟消费者、取消、预算、忙循环、恶意错误 getter、消费者异常、超过旧上限的大记录、同刻前缀与事务回退、随机事件/时间跳转、重算哈希后的规则伪造、档案导出导入与不完整文件。

实际 Electron 子进程专项包含正常完成、启动即取消、批次后取消、子进程崩溃、注入 ENOSPC 及 64,008 事件的大记录。开发版大记录实测运行器缓冲峰值 72 条、校验器 8 条、随机窗口最多 256 条；100 个跳转与执行时独立保存的世界逐项一致。导出约 108 MiB。此负载是 8×8、8 机的等待循环，用于验证记录规模，不作为混合作物、动画丰富度或 30 分钟性能达标证据。

开发验证目录：`artifacts/stream/utility-dev/`、`ui-dev/`、`regression-dev/`。最终发行包验证汇总见 [stream-release-verification.json](stream-release-verification.json)。
