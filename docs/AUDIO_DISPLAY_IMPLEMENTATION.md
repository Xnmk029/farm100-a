# 独立声音与高 DPI 布局

2026-09-10。当前为教学检查点之后的源码改动，不在已冻结的 alpha.2 大农场包内。

环境、动作和收获有独立音量及静音开关，总开关默认关闭。三个实际 Web Audio 增益通道控制已创建的声音，静音也会迅速衰减尚未结束的音符。进入独立课程时暂停原农场声音。所有声音均为本地合成，无外部采样。

只给已经完成的动作播放反馈，忽略派发、屏障和只读查询。旧规则返回 0 的空收获与返回 false 的失败均采用失败动作音，不能触发收获奖励音。补齐交换、区域整地/浇水/收获、施肥、加工、维修与探索收集的反馈。动作与收获分别按真实音频时钟限流，间隔为 100/140 ms，避免八台同刻操作或高速回放堆叠；完整逻辑事件不变。

在较短窗口中，农场去掉 660 px 的强制最低高度，压缩非必要留白，让侧栏内容可以滚动，保留编辑、执行、回放、镜头、资源观察与声音入口。主窗口最小外部尺寸改为 900×500，以适配高缩放屏幕。常规大窗口保持原布局。

## 验证结果

`scripts/audio-display-verify.mjs` 的完整结果在 `artifacts/audio/final-20260910/verification.json`，全部通过：类型检查、54/54 全量测试、构建、11 项真实 OfflineAudioContext 渲染、100%/150%/200% 实际 DPR 窗口回归。

音频检查使用与产品相同的合成源码，保存源码/构建 SHA-256、每个案例的 PCM 波形及 RMS/峰值。检查各通道单独输出、静音的精确零输出、半音量对应半幅度、失败收获、派发事件静音、已经排入播放的声音被静音，以及峰值不削波。离线波形不能证明设备扬声器表现或主观听感。

页面覆盖自由农场、课程、研究、加工、任务、历史和挑战选择。100% 测 1280×720 与 1920×1080；150% 测 1280×720 CSS（1920×1080 像素）；200% 测 960×540 CSS（1920×1080 像素）。课程实际执行并显示未通过反馈；音量和静音控件逐个变更，单独取消动作静音不会改变其他通道。各界面没有文档溢出或画布错误，检查的操作可通过面板滚动到达。

最初三次 200% 尝试实际 DPR 仍为 1，没有计入通过。Electron 42 起离屏窗口默认固定为 DPR=1；之后改为原生可见窗口并断言实际 DPR，再复现并修复高度溢出。[Electron 官方变更说明](https://www.electronjs.org/docs/latest/breaking-changes#behavior-changed-offscreen-rendering-will-use-10-as-default-device-scale-factor)

200% 农场与课程截图已查看，执行、编辑和回放区域可用。所有源报告保留，旧失败不覆盖。该回归未覆盖旧排序界面及双方案对比的高 DPI；干净 Windows、原生文件对话框、真实设备听音、最终演示录像及新手/外部评价仍需后续验收。
