# 排序农场规则与 API v1.0

规则标识 `sort-field-v1.0`，引擎/协议 `0.1.0`，参赛语言 JavaScript，运行器 `quickjs-emscripten@0.32.0`。P0 原型验证通过后固定这组首版选择。

## 世界

- 正方形 4×4、8×8、16×16；每格 0～9，允许重复；所有作物初始成熟。
- 左上角为 (0,0)，x 向右，y 向下。无人机初始 (0,0)，边界不环绕。
- `North`、`South`、`East`、`West` 为注入的方向字符串。
- 成功需要每行从左到右、每列从上到下非递减，当前数值多重集合与初始地图完全一致，最后调用 `harvest()`。
- 未成功收获就结束的程序为 incomplete。初始已排序也必须显式收获。
- 收获成功即终止，保留最终排序网格。脚本即便捕获异常，也不能继续改变世界或预算。

## 接口

| 接口 | 返回 | 成本 |
| --- | --- | ---: |
| get_size() | 边长 N | 1 |
| get_position() | 独立对象 {x,y} | 1 |
| move(direction) | 合法移动 true；越界 false，位置不变 | 1 |
| measure() | 脚下整数 | 1 |
| measure(direction) | 相邻整数；越界 null | 1 |
| swap(direction) | 交换相邻格值返回 true；越界 false | 3 |
| harvest() | 条件未满足 false；条件满足由宿主终止为 succeeded | 1 |

查询参数严格校验：无参数接口不接受多余参数；move/swap 必须恰有一个合法方向；measure 允许 0 或 1 个参数，显式传 undefined/null/数字/对象均为 api_error。参数错误不扣费，不改变世界，并终止整个运行。

合法调用发生越界或未成功收获仍然收费。顺序为参数校验 → 预算预检 → 扣费 → 状态变化 → 分类计数 → 唯一事件。剩余预算不足以支付完整动作时，不扣费、不执行动作，并终止为 budget_exceeded。

刚好用尽预算时，如果本次动作成功收获则通关；若脚本自行结束但未收获，则 incomplete；继续调用 API 会触发预算耗尽。

标准测试预算：4×4 为 2,000，8×8 为 20,000，16×16 为 200,000。可配置范围 0～1,000,000；不同预算配置不纳入同组正式比较。

## 执行

标准 JavaScript 计算与 Array.sort 可用，只能通过上述 API 影响世界。接口在脚本看来同步执行。首版不调度用户 Promise 作业、定时器或外部异步模块；异步任务不能替代顶层程序通关。

不暴露 process、require、fetch、Date、Math.random、文件、网络、Electron 或系统能力。模块加载被禁用。

QuickJS 分配内存上限 128 MiB，VM 墙钟上限 30 秒，宿主 35 秒强杀兜底。用户中止先请求协作退出，1 秒后仍未退出则强杀。代码限制 1 MiB；日志限制 256 KiB，单条最多 4 KiB，超限截断并标记；最多 250,000 个动作事件，超限终止，不能静默丢计分事件。

上述 VM 内存限额不是整个 Electron 进程的总内存上限。内部计算不计入世界逻辑成本；墙钟异常终止的位置可能因机器而不同，不视为确定性事件序列。

## 随机与比较

地图采用 `mulberry32-v1` 整数 PRNG，种子为 uint32；运行包同时保存初始地图。自定义局面以 initial 数组输入，必须恰好 N² 个 0～9 的整数。

先比较通过率；成功解法再比较相同案例的总逻辑成本，分类次数用于解释差异。失败时显示剩余相邻违反数，仅作为诊断，不作为通关替代分数。播放倍率和本机耗时不参与逻辑成本。

人工参考解逐行冒泡再逐列冒泡；改进解缓存测量并使用相邻插入排序。固定测试集上二者均通关，改进解成本更低；没有声称改进解对所有可能局面最优。
