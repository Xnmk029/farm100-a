# 挑战评分 v1 与 Luna 运行复核

本轮新增 `challenge-score-v1`，适用于 `garden-v0.5.0`。评分从实际运行记录计算，不改变题目预算、通关条件或历史模拟规则。

## 评分规则

- 目标完成度满分 100：每项目标的 `min(实际值/目标值, 1)` 等权平均后乘 100，显示两位小数。负值按零计，超额产出不补偿另一项缺失。完成度是进度，不是通关或综合能力分。
- 效率入榜要求：完整运行、正常结束、所有目标达成。先完成目标再异常退出仍不入榜。
- 排名以题目 `primary` 指定的模拟 tick 或操作成本升序排列；相同时比较另一指标，再比较失败动作数。全部相同并列，采用 1、1、3 名次。
- 同规则、同题、同种子、同部署、同配置及同初始世界才进入同一组。不同部署可继续并排回放，但不给跨配置效率评分。历史版本不套用新评分。
- 双方案相对效率为 `(1 - B主指标/A主指标) × 100%`，正值表示节省、负值表示增加；仅双方同配置通关且 A 指标大于零时计算，不是综合质量分。
- 有效作业台数、成功作业数和通信调用数是诊断信息，不额外收紧旧题通关规则。只数已完成事件；派发不重复计数，身份/数量/时钟查询不算通信。读写共享状态、原子操作和屏障计为通信调用。当前部分 fleet 题允许多数机器不作业，这一现象会显式显示。

新分数出现在挑战结果、会话记录和并排对比中。排名范围为本次会话；不声称已有在线跨用户榜单。批量评测输出 JSON 和 CSV，保留完整指标，避免用一个任意加权总分掩盖失败或性能差异。运行入口同时补充同步 API 示例，明确不支持通过 async/await 延续执行。

## Luna 原始记录复核

复核程序读取四个保留阶段的原始记录，逐一调用规则验证器；另外重新执行最终 18 份源码，核对完整事件、终态、结束原因和完整标志。18/18 均成功复现。模型身份来自委派配置和原报告；事件记录自身不证明作者身份。

| 阶段 | 通过数 | 通过率 |
| --- | ---: | ---: |
| 首次提交（17 条入口失败，maze-3 缺原始记录） | 0/18 有通过证据 | 0%（保守分母） |
| 首次完整算法运行（round-2） | 16/18 | 88.89% |
| 根据反馈修订后的最终结果 | 18/18 | 100% |

最早阶段只找到 17 条原始记录，maze-3 缺证；不能把缺证说成已执行失败，报告已列出 missingIds。round-1 的异步包装仍不能等待 Promise，单独保留而不抹去。`farm-2` 的作用域错误和 `fleet-repair` 的定位问题各在之后修订一次。不能将最终 100% 叫作首次提交通过率或 pass@1。五个家族的分项结果、每题完成度、主次指标和所有阶段的文件/源码 SHA256 均进入报告。

题目难度结论仍有限：只测固定种子 42、一个模型和这些部署配置；12 课没有测试。`schedule-2 → schedule-3` 的编号梯度不稳定，部分 fleet 题只要求最终资源，不要求协作。评分 v1 先把效率与参与情况明确呈现；若增加协作或过程硬约束，应建立新版本题目并重新验收，不能追溯改写这次 18/18。

## 复用与证据

```powershell
node node_modules/tsx/dist/cli.mjs scripts/score-challenge-suite.ts artifacts/difficulty-luna-20260910 artifacts/scoring/luna-20260910 --rerun --baseline
```

批处理当前接收本次代理的阶段目录格式：`raw/round-1-syntax-entry/<id>.json`、`round-1`、`round-2`、`round-3`；文件内必须有完整 `run`。不执行文件内声称的 sourcePath，只使用记录内保存的源码。该入口是适配此实验协议的复核器，不是任意平台通用的成绩导入。

- `artifacts/scoring/luna-20260910/score-report.json`：完整复核与阶段评分。
- `artifacts/scoring/luna-20260910/scores.csv`：18 题成绩表。
- `packages/garden/scoring.ts`：可复用的单题评分、分组排名和效率比较。
- `tests/challenge-scoring.test.ts`：真实执行验证失败不入榜、并列、配置隔离、派发去重、篡改拒绝及多目标封顶。

评分函数用于已在执行/导入边界完成验证的记录；批处理会独立重验，不信任代理摘要中的通过标记。缺失或无效证据不计通过，复核或重执行不一致时命令以非零状态结束。

## 同配置基线对照

`--baseline` 另行实际执行仓库自带的朴素基线，使用每题与 Luna 最终记录完全相同的配置，保存校验后的基线记录及源码/文件哈希。基线不是最优解或满分上限，比较发生在独立解题结束之后。

本次 18 个基线均通关且可比。Luna 在 12 题上减少了主指标，在 6 题上增加了主指标；不能由最终 18/18 推断其策略都高效。

| 题目 | 主指标 | Luna | 朴素基线 | Luna 相对变化 |

| 闭环堆肥 | cost | 1897 | 35216 | 节省 94.61% |

完整 18 题在 CSV/JSON 内，未对这些不同任务的百分比强行加总。单种子观测不用于直接调整题目难度级别。
