## 观察到的设计语言

1. 白场承担阅读，黑场承担章节重音；钴蓝和青色作信号，不是给每张卡片铺颜色。
2. 大拉丁字形是视觉容器，内部流动材质与稳定轮廓分离。中文判断保持实心。
3. 0–0.6 秒样帧显示识别元素从集中呈现过渡到完整构图；约 4.5–5.5 秒切片打开黑场。此为采样观察，不反推精确速度曲线。
4. 证据窗口、标题和简评分区明确，内容左边界延续。角标、短线提供定位，不承担主要信息。
5. README 特别要求证据停留加长、过场各自有时间；不可通过压缩全片或叠加全部动画取得“快感”。
