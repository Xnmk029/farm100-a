# 像素欧普材质补充规范 v2.1

2026-10-04。来源：用户提供的 unbox-swe2max-tone demo、c2-titlecard-V14-f2634.png、devin-mark/HOW.txt，以及用户对 v2 样机的反馈。本文件覆盖 design.md 中对材质的过度收缩解释；不改变模拟、评分或历史结果。

## 纠正的偏差

v2 主要继承了白底、钴蓝、斜势中文与空间线稿，没有把参考最有辨识度的像素欧普材质实现出来。薄板结构可以保留，但视觉身份需要由固定字形中的阶梯色带与黑白干涉建立。像素欧普是主视觉要求，不能作为以后可选的装饰。

## 形状与颜色

- 拉丁展示图形用窄长、开放内白、像素台阶边缘的稳定轮廓。v2.1 的 FARM 是独立绘制的几何字形，不借用其他模型的标志，也不靠拉伸普通字体形成。
- 主材质由深蓝、钴蓝、青色、浅青组成宽色带；紫、品红和酸绿仅作局部转折。采用离散色阶，不做光滑彩虹渐变、金属高光或全屏噪声。
- 黑白欧普区以弯曲条纹和棋盘干涉形成局部块面，置于笔画内部。轮廓边缘保留颜色，避免细笔画被干涉纹切断。
- 中文短标题保留得意黑单色。代码、分数、结论、来源与状态图例不填纹理；不让材质颜色暗示成绩优劣。
- 边角保留小型四色套准点、十字定位与短线。它们是静态辅助标识，层级低于字形和内容。

## 尺寸与纹理层级

| 载体 | v2.1 实现 | 后续项目要求 |
| --- | --- | --- |
| 片头展示字 | 176×132 固定 FARM 掩模，4.5 倍最近邻显示；每源像素约 4.5 屏幕像素 | 可见台阶与宽色带，不磨平为渐变；几何高度和字号分别管理 |
| 侧栏标记 | 2.2 倍横屏、1.12 倍竖屏；色场按 2×2 源像素合并采样 | 缩小后减少干涉细节，保留字形识别 |
| 空间小顶面 | 8×8 色块，局部 UV；深色侧面 | 依据实际投影尺寸选择 4×4、8×8 或更高档位，避免把完整片头纹理缩成雪花 |
| 田地边缘 | 交替蓝/青短色带 | 极薄表面使用少量纯色分段，不放密集棋盘 |
| 正文与证据 | 单色、无动态纹理 | 始终保持可读，截图原色不变 |

尺寸档位是设计要求，样机只实现表中两种字形尺寸和一种顶面档位；尚未实现任意缩放的自动档位系统。

## 动效与 3D 衔接

材质仅由坐标与时间计算：`phase = 2π × (time mod 12) / 12`。用连续波形扭曲采样坐标，再量化成色阶；空间扰动来自固定散列，禁止每帧重新随机。0 秒和 12 秒的材质相同，3 秒的材质不同。12 秒只约束材质循环，不要求整段 18 秒镜头循环。

轮廓、字距和位置不随材质抖动。空间动作使用原有平滑曲线，不加弹跳。纹理绑定物体局部 UV，随顶面共同投影；相机展平过程中保持同一张面，不到最后突然换贴图。侧面保持实体明度，阅读层始终正视。

同一画面共享材质时钟。v2.1 相同顶面共用同相位纹理；后续资产若需要错开纹理区域，以对象 ID 确定固定坐标偏移，不能每次播放重新抽样。减少动效时材质相位固定为 0，关闭分层和自动运镜过渡。

镜头保留“像素大字 → 空间展开 → 深度归零 → 关系分层 → 阅读归位”。进入代码和成绩密集段时，包装纹理应减小或停止，不能遮住证据。实测视频中的世界时间仍由归档事件决定，装饰时钟不影响结果。

## 跨项目落点

| 区域 | 采用方式 |
| --- | --- |
| 启动页、章节入口 | 大字材质作为主要视觉锚点，留出单色中文说明 |
| 农田、迷宫与自由经营 | 关键实体顶面或标记使用材质；几何轮廓和标签承担业务状态 |
| 编辑器与任务说明 | 稳定单色阅读区，仅章节标记与小面积边沿继承品牌 |
| 回放与分析 | 相机变化不改变纹理锚点；选中对象与路径仍用清晰轮廓 |
| 成绩、错题和归档 | 数字与证据保持正视，包装图形退到次要区域 |

这些是全项目迁移要求。本次交付是独立风格样机，没有完成业务客户端换装。
