蓝/青阶梯色带与局部黑白干涉纹用于拉丁展示字、识别标记及选定的空间顶面。固定轮廓、统一 12 秒相位、确定性空间采样；正文、代码和成绩保持单色。全画面 3–8% 的主色目标用于常规阅读页，包装大字可突破，不能用这一比例抹掉参考的识别特征。v2.1 已独立实现材质试验引擎；参考包没有提供完整 PHASE 源引擎，不宣称逐像素复刻。

## 3. 字体、网格与信息密度

- 中文 2–6 字展示标题：得意黑，自带斜势，不再 skew。常规 96–128 px；144 px 仅留给有证据且明确批准使用的“整体优秀”特写，默认不启用。
- 中文长标题与正文：思源黑体 SC，真实 Regular / Medium / Bold 文件；禁止拉伸和伪粗。拉丁与数据：Source Code Pro。样机临时字体差异写入 QA。
- 展示中文每帧只保留一处。大拉丁字形可作空间入口，不与中文标题同等抢眼；不得用大号 FARM 字母替代必要的内容。
- 8 px 间距网格，4 px 材质网格；中文 0 字距。大字与证据至少 32 px 间隔。
- 16:9 视频 1920×1080：左右 96，顶部 72，底部 72；主标题 96–128，正文 32–40，代码 28–32，来源 24。不可把关键结论缩为 16 px。
- 9:16 视频 1080×1920：沿参考 x88–992；标题 96–128，正文 40–44，代码优先节选 30–34，来源 24–26。字幕专属区域与简评分开，平台 UI 遮挡区在发布时再核对。
- 桌面工作模式用逻辑 CSS 像素：正文 14–16、分组标题 18–24、页面标题 28–40、数据 24–48、代码 14–18。不能直接套视频字号；不得恢复原界面大量 9–11 px 关键说明。
- 长句按实测字宽换行；标点不落行首，模型名、数值与单位不拆；长源码保留行号、明确省略，提供完整文本入口。

## 4. “3D 空间平面化”的空间规则

### 4.1 相机

默认正交投影，无近大远小。世界单位定义为一格田地，地面 XY、向上 Z。相机旋转围绕当前关注区域中心，而非画布左上角。

| 视图 | 离俯视的倾角 α | 平面旋角 ψ | 使用 |
| --- | --- | --- | --- |
| 平面核对 | 0° | 0° | 排序、路径审查、坐标、严肃比较 |
| 作业阅读 | 40–52° | 35–45° | 单田生产、无人机动作、视频能力段 |
| 展开说明 | 52° 上限 | 当前角度 ±12° | 观察资源层与因果；仅短时 |
| 信息正视 | 屏幕正对 | 0° | 代码、分数、表格、字幕 |

世界点投影：`u=s*(x*cosψ-y*sinψ)`；`v=s*((x*sinψ+y*cosψ)*cosα-z*sinα)`。屏幕中心、缩放 s 独立定义。展平时 α 和 ψ 同步归零，Z 引起的屏幕位移随 sinα 消失。物体侧面面积平滑降到零，不能最后一帧突然替换。

每次相机变化必须核对整个过程中投影包围盒，而非仅检查起止姿态。倾角和旋角同时改变时，中段画面可能比两端更高；按包含侧面、飞行高度与分层高度的最大范围适配舞台，给标题和页脚留独立区域。样机已增加双画幅全 2160 帧空间边界校验。

禁止无限环绕、自动摇摆、眩晕式滚转或用透视夸大某模型成果。首版不引入透视模式。若将来需要，另建规范，不混入同一比较画面。

### 4.2 三个坐标层

1. 世界层：土壤、作物、无人机、障碍；真正随相机投影。
2. 关系层：路径、邻接线、目标格和触点；锚定世界，线宽保持屏幕尺度。
3. 阅读层：代码、数字、标签、图例和字幕；始终屏幕正视，不受倾角压缩。

标签以世界投影点为锚，偏移量限制 24–64 px；冲突时转到侧栏并保留引线。不能依靠把标签转到侧面来腾空间。字幕位于最上层，世界穿越不得遮挡字幕。

### 4.3 深度与形体

- 地面板厚 0.04–0.08 格；边沿是薄切面，不做厚重漂浮岛。
- 作物形体高度 0.18–0.65 格，用轮廓和阶段区分种类，不能只换色；密集视图可折叠为顶面符号。
- 无人机作业高度 0.35–0.55 格，影子对应地面实际坐标，编号放阅读层；待机没有业务位移。
- 说明性分层总高不超过 1.2 格，最多 3 层：地面→状态/路径→动作结果。超过就拆镜头。
- GUI 面板挤出 0；仅空间入口短暂出现 6–16 px 边厚，落位后归零。不能把每个按钮都做成 3D 方块。
- 地面块、作物与无人机用 2–3 面硬边轮廓；倒角半径不超过尺寸的 4%。默认无连续高光滚动。

### 4.4 遮挡、阴影与透明

按相机深度稳定排序，同深度按对象 ID 排序，避免抖动。当前主体被遮住时优先降低前景物体高度/轮廓化，而非整片透明。活动目标必须有可见的地面锚点。

单一固定左上光向，环境明度统一；接触阴影不跟相机任意旋转。影子不作为成功/失败含义。最大不透明度 12%，模糊 8–16 px；平面核对时缩为小接触影或关闭。

文字不投影、不发光；代码与证据窗始终清晰。半透明叠层至多一层，禁止多层玻璃使网格、路径和作物混色。

## 5. 连续动效语法

每次动作标出“从何处来、为什么变化、到何处去”。优先同一边缘/对象连续变形，少用遮掉全部画面的过场。黑白换场沿稳定切口推进，保留角标和坐标锚点；禁止全屏亮暗来回闪烁。

| 动作 | 时长提案 | 曲线/次序 | 含义 |
| --- | --- | --- | --- |
| hover / focus | 100–140 ms | ease-out，颜色或 1 px 轮廓 | 可交互，不缩放正文 |
| pressed / selected | 160–220 ms | ease-out，最多 2 px 位移 | 状态确认 |
| 侧栏展开 | 280–360 ms | cubic-bezier(.22,1,.36,1) | 保持世界区域中心 |
| 页面共享元素换位 | 420–560 ms | 同边界起止 | 历史记录进入回放 |
| 土地空间展开 | 650–900 ms | quintic smoothstep | 呈现深度关系 |
| 作业视图→平面核对 | 800–1000 ms | quintic smoothstep，零端点速度/加速度 | 相同田地展平，阅读层不转动 |
| 关系层分离/合回 | 600–800 ms | 基底先稳定，关系层后移 | 因果拆解，最多 3 层 |
| 视频切片揭幕 | 600–900 ms | 单方向，前后有停留 | 参考包方式的 FARM100 扩展，不宣称逐帧复制 |
| 代码定位 | 220–320 ms | 行底纹展开后显示批注 | 不让整段代码乱跳 |
| 结果提交 | 360–500 ms | 数值直接落到真实值，分项线展开 | 不用随机滚数伪造计算过程 |

曲线统一：交互快速缓出；空间变换用 `6t^5-15t^4+10t^3`。无弹簧回弹、过冲缩放、随机抖动。连贯同方向运动要匹配速度；不能每张卡片都从零加速一遍。

同一时刻至多一个结构性运动 + 一个局部反馈。相机运动时不同时翻页、计分滚动、路径闪烁。微标记可延后 60–100 ms 出现，不把整条队列拖长。

用户拖动进度条时立即响应；不把 900 ms 相机动画叠到每次拖动。新命令打断旧命令，从当前显示姿态过渡到新目标，不排队；选中、焦点和模拟状态立即更新，动画只是表现。

## 6. 农场动作与判题事件

| 行为 | 空间表达 | 事实边界 |
| --- | --- | --- |
| 移动 | 从起点到终点投影插值，机身朝向轻转 ≤8°，落位稳定 | 使用真实开始/结束 tick；不跨越未执行路线 |
| 播种 | 工具触点→格内种子轮廓建立 | 成功 complete 后才建立持久种子状态 |
| 生长 | 分阶段高度和轮廓变化 | 来自模拟成长字段，不靠墙钟自动长大 |
| 收获 | 局部物体收拢，数量标签流向库存 | complete 成功后更新库存；装饰飞行不延迟真实数据 |
| 交换 | 两株沿互不混淆的短弧换位，双端格保留 | 不改变实际交换时序 |
| 维修 | 断线轮廓闭合→恢复实体 | 返回 false 只显示一次未完成标记，不播放成功粒子 |
| 等待 | 固定位置、细线时间带延伸 | 禁止画成巡逻；旋翼装饰可关，不计动作 |
| 多机 | 不同编号、轮廓/线型、同时间基准 | 部署数量不等于有效协作，负载差异保留 |
| 迷宫 | 已见区域展开为低墙，未知区域是平面遮片 | 不提前展示未知通路；赛后全图需明确标注 |
| 预算/异常 | 锁住最后有效状态并标原因 | 语法错误使用 0 tick 平面代码页，不能补造行走 |

高速播放仍按 tick 恢复状态；小于可辨时长的多次成功反馈聚合显示数量，不拉长事件改变通关时间。暂停保留状态且停止非必要动效。业务声音只跟 complete 事件，dispatch 不重复发声。

## 8. 视频导播与双画幅

单模型节目仍按“任务→策略→真实执行→结果与代价→错题根因”组织。第一次出现任务先用一行中文讲交付目标，再给场景。分数只在需要解释时出现。

正式片预算建议：真实运行/证据 65–75%，解释与总结 20–30%，纯包装不超过 10%。这是新的制作目标，不是对参考片已达到的描述。目标时长由证据与实配旁白决定，不沿用固定 72 秒硬塞。

空间是过渡和解释工具：展开田地进入行为观察；识别路径时展平；选中错误的格子或事件后，同一锚点引出代码；代码与成绩保持平面阅读。没有记录的算法思路只能标“代码分析”，不能画成实时内部思考。

16:9：主世界位于左/中，解释侧栏右侧；完整证据可以临时占满画面。9:16：标题→世界→简评→来源纵向排布，保留足够大的世界窗口；不把横屏整体缩小塞入手机屏。长代码取关键行，完整日志给链接。

相同语义对象可共用数据，不能共用固定像素布局。比较影片两方条件相同；侧边状态不能在切片中丢失几帧。字幕最多两行，独占阅读区，不能压代码或网格关键动作。

声音规划：空间揭幕轻扫、动作完成短触点、错误单次克制提示；配音主导节奏，静音仍可理解。参考音乐仅为参考包内容，不默认移入 FARM100 成片。

## 9. 技术落地与可访问性

保留 React + PixiJS + 现有模拟器。浅几何、排序层、正交投影可由现有 Pixi 承担，不为风格直接更换判题或游戏引擎。若高密度场景需要真正 3D，再单独验证渲染适配层。

计划分出 `visual-tokens`、`projection`、`world-renderer`、`screen-overlay`、`motion-clock`、`director-cues`。视图只消费状态；事件统计仍由已有引擎产生。视频与交互预览共用相机、布局和样式函数。

回放时 `visualState=f(snapshot,eventTime,cameraPose)`，任意 seek 可重建，不依赖前一帧累积。装饰相位独立且确定性，截图和导出使用同一帧时钟。暂停、后台和不可见区域停止持续刷新。

目标：客户端 1080p 常见 8×8 / 8 机场景 60 fps，p95 帧时 ≤16.7 ms；较大田地降装饰、减少标签、关闭阴影优先，不隐藏业务状态。此为验收预算，尚非现有性能结论。离线视频 60 fps，可显式派生 30 fps，不能用加速音轨补时长。

支持 reduced-motion：取消自动相机运动、分层位移和材质流动，保留直接状态变化与短边框确认；降低动效不删除证据内容。键盘焦点可辨、所有控件可键盘触发、状态通过文字同步。无循环闪烁；警示闪烁最多每秒 2 次且默认不用。实际对比度需检查，主正文目标 ≥4.5:1。

## 10. 迁移顺序与验收门槛

| V0 本轮 | 参考审计、本规范、token、独立空间样机 | 展开/展平可播放，横竖排版可审查；明确为动效演示 |
| V1 视觉基础 | 锁定字体与许可证，浅/深主题、导航、列表、表单 | 工作模式可读、焦点和空态完整；不改判题 |
| V2 世界与回放 | 新地面、作物、无人机、正交相机和事件适配 | 同记录旧新视图终态一致；0/中间/终态与 seek 可复现 |
| V3 成绩与错题 | 同锚点世界→事件→源码联动 | 覆盖/通过/满分分离；语法失败无伪动作；原文可追溯 |
| V4 节目生产 | 一个真实代表题完整片段，配音/音效，双画幅 | 证据停留够长；实片抽帧、解码、读字、事件对齐通过 |
| V5 扩展 | 全题型与多模型参数化 | 选案例和结论需校核，禁止仅换模型名套结论 |

视觉验收分别检查：固定角度空间层次、过渡首尾和 25/50/75% 中间帧、密集遮挡、多机身份、代码和字幕安全区、移动端关键文字。像素边界检查不能代替人眼遮挡复查。

技术验收：帧时分位数、缓存内存、同帧确定性、动画打断、后台暂停、reduced-motion、导出色彩/帧率/全片解码。内容验收：所有数字与归档一致，未知项不补 0，展示切片不会改变效率分。

本轮独立样机用明确标注的演示几何检验视觉语法；不伪装为某模型实际执行，不代表业务客户端已经换肤或全题型已经实现。
