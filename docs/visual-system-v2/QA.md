- 横屏有 MP4；竖屏有同源交互布局与样帧，尚未另出竖屏视频。没有配音或音效。
- 60 fps 是导出规格，不是已证明业务客户端在全部规模下运行到 60 fps；性能和可访问性完整验收列入后续阶段。
