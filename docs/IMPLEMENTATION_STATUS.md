## 验收边界与已知限制

- 干净 Windows 机器/VM 的安装、卸载和离线复现尚未验收；在开发机启动分发版也不能替代这一项。
- Windows 原生自动化辅助工具读取界面文本成功，但截图遇到 `SetIsBorderRequired` 接口错误，点击遇到几何信息不可用；因此没有将文件对话框、全部鼠标操作的自动化验收标记为通过。视觉检查使用项目内 Electron 离屏渲染测试，运行与存档另有真实数据证据。
- 原子保存目前发生在单次运行结束。运行器异常退出可保存已确认事件前缀；客户端主进程/系统整体崩溃时，未封存的进行中运行不可恢复。后续应加入持久化事件日志。
- “运行记录”页当前只显示本次会话记录；历史文件可重新导入。持久化历史检索尚未实现。
- 场景显示交换两格高亮及真实数值变化，无人机有位置插值；尚未实现植物在两格之间交换的完整补间动画。
- 无模型 API 自动调用、Python、多无人机、其他关卡或视频导出；按原计划这些属于后续版本。
- 文件大小、日志和事件数量有硬上限，但 Electron 宿主总内存尚未采用 Windows Job Object 限制。VM 分配上限不能等同于整个进程内存上限。

下一轮验收重点：干净 Windows 安装验证、文件对话框与完整鼠标流程、持久化历史和进行中日志恢复。先根据客户端实际使用反馈调整，再扩展第二关。
