# G4 多无人机协议（实现前冻结）

版本目标：garden-v0.5.0 / fleet 调度事件 v1。此文规定实现语义；验证记录另列，未验证项不计完成。

每次调度选择 1 / 2 / 4 / 8 台无人机。各机使用独立 QuickJS/WASM 模块和独立全局对象，运行同一份用户程序，通过 get_drone_id()、get_drone_count() 分工。局部变量、函数和执行栈互不共享；不能直接访问其他机的堆。共享世界包括田地、生长、研究和资源库存。

自由农场分阶段研究解锁 2 / 4 / 8 机；挑战由版本化关卡规定可用数量，不继承自由农场科技。部署数量必须经引擎校验。旧 0.2、0.3、0.4 世界按各自冻结规则验证。

## 时间与提交

每台机一次只能挂起一个 API。纯 JS 计算不推进模拟时间，并受 VM 指令、内存和宿主时限保护。调度器先让当前可运行无人机按 ID 升序到达下一个 API 或结束点，形成完整等待集合后，才推进至最早完成时间。相同完成时间按 ID 升序提交全部动作，然后按 ID 升序恢复这些程序。不得由 Promise 或 Electron 消息到达顺序决定逻辑时间与胜负。

作物只按全局时间差生长一次。API 在发起时验证参数、预留操作预算，完成时按共享世界检验资源/田块条件并提交；资源不提前锁定。动作失败仍消耗其持续时间及成本。同 tick 的争用由稳定 ID 次序决定。预算涵盖所有机，分别报告总成本、各机成本和整体完成时间。

无人机可以同格悬停及相向穿越，画面使用稳定的颜色/悬停位置区分。共享田块的操作仍受完成次序约束：同刻采收只有第一台拿到作物，后续调用返回 false；同刻消耗最后一份材料也只有先提交者成功。不把共享空域误当成资源互斥。

## 协作 API

- get_drone_id() / get_drone_count() / get_time()：各 1 tick、成本 1。
- read_shared(key)、write_shared(key,value)、compare_exchange(key,expected,replacement)：各 2 tick、成本 1。共享值为有限数字、布尔、null 或最多 1024 字符的字符串；键最多 64 字符，最多 128 个键。复合消息可由程序自行 JSON 编解码。
- compare_exchange 原子比较旧值并条件替换，返回 {exchanged,value}；不存在的键读为 null。可据此实现任务队列、计数器和锁，不提供隐式万能调度。
- barrier(label)：全体部署无人机到达相同标签后，再用 1 tick 同时释放，按 ID 提交；每台成本 1。已经结束的机不会被自动当作到达。若剩余动作全为无法满足的屏障，报告 deadlock，保留明确诊断，不永久挂起。

取消、非法 API、预算/内存/计算限制会终止整次调度，撤销尚未提交的动作，保留已提交的世界。记录 dispatch、complete、finish、abort 及完整队列/机位/共享状态，回放不得只恢复最后一台的位置。继续编程从所选世界重新调度，不声称恢复 QuickJS 执行栈。

## 验收门槛

至少两个真实程序体现分工收益，一个体现争用/通信开销；1/2/4/8 机重复结果一致。测试包括同刻采收、末份材料、原子任务认领、屏障、死锁、取消、预算不足、局部堆隔离、恶意异常、旧规则兼容、完整日志及 100 点跳转。界面须同时展示多台实际动作及等待状态；随后验证混合生产、多家族挑战和从新档解锁的完整流程。
