## 教学内容与实际判定

每课提供背景、目标、解释、未完成起步代码、逐条展开的提示及真实执行反馈。练习从固定初态重新运行，原始事件写入既有历史，完成后可以逐时刻回放。反馈判定实际动作和世界变化，不用代码字符串匹配来声称已经学会某个概念。

| 课 | 概念 | 本课运行中的判定 |
| --- | --- | --- |
| 1 | 坐标、调用、返回值 | 移到 (1,0)，读取移动后的位置 |
| 2 | 布尔值、边界 | 四次向东，前三次成功，最后一次失败且不绕回 |
| 3 | for 循环 | 四格翻土，只走三步 |
| 4 | 动作顺序 | 一行四株麦，每格浇水 |
| 5 | if/else | 收获成熟株，给幼苗浇水且保留它 |
| 6 | while、模拟时间 | 观察成熟后收获，180 tick 内完成 |
| 7 | 函数复用 | 补全函数后完成 2×2 播种 |
| 8 | 变量记忆与累加 | 仅采两株成熟麦，输出本轮数量 2 |
| 9 | 嵌套循环、蛇形路线 | 覆盖 16 格，最多 15 次移动 |
| 10 | 生产调度 | 16 株完整种收，不调用 wait，最多 560 tick |
| 11 | 库存条件、资源预留 | 研究根菜、种两株，保留至少 1 粮食 |
| 12 | 综合迁移 | 零粮食新档生产至少八株麦，研究并保留四株根菜 |

所有课都要求正常结束；除专门观察边界的第二课外，不接受失败动作和提前收获。检查初态，且从本轮增量判定收获，不能拿历史成就直接通过。带初始作物或库存的练习由同一 Garden 引擎执行准备动作生成，没有向自由农场注入资源。

主进程根据 lesson ID 生成初态、配置并判定实际运行；不会信任练习请求携带的自由农场状态。每课草稿和完成记录保存在本机 localStorage，完成条目关联实际运行 ID。该记录是学习辅助，不是竞赛成绩，也不证明学习者已掌握概念。
